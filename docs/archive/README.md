# 資料アーカイブ

このディレクトリには、公開仕様書・利用ガイドとは分けて保管する検討記録、性能評価、試作記録、作業ログを置きます。資料は削除せず、役割と作成時点が分かる形で保存します。

| 区分 | 格納先 | 内容 |
| --- | --- | --- |
| AI研究・評価 | [ai-research/](ai-research/) | モデル選定、品質評価、性能計測、設計記録 |
| 旧AI検討資料 | [legacy-ai-research/](legacy-ai-research/) | 以前の調査と品質検討の記録 |
| 開発・試作記録 | [records/](records/) | デプロイ記録、物理出力試作、進捗資料 |

公開仕様は[資料トップ](../README.md)から参照してください。
